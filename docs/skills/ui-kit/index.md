For projects with a `components.json` (shadcn/ui).

**Role in the lifecycle:** **Build**, model-invoked: the agent loads it whenever it adds, composes or styles shadcn/ui components.

<!-- skills:start -->
## Skills

- [`shadcn`](./shadcn.md) — Manages shadcn components and projects — adding, searching, fixing, debugging, styling, and composing UI. Provides project context, component docs, and usage examples. Applies when working with shadcn/ui, component registries, presets, --preset codes, or any project with a components.json file. Also triggers for "shadcn init", "create an app with --preset", or "switch to --preset".

Install the whole group:

```bash
npx skills@latest add Phenomenon-Studio/phenomenon-skills --skill shadcn
```
